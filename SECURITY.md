# Security Policy

## Reporting Security Issues

The Submariner maintainers take security seriously. We appreciate your efforts to responsibly disclose your findings.

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, please report them through our [private vulnerability reporting](https://github.com/submariner-io/submariner/security/advisories/new) form.

For more details, see the [Submariner security policy](https://github.com/submariner-io/submariner/blob/devel/SECURITY.md).
